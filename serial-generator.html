What this is for

Most test batches and inventory rollouts don't need one code typed at a time — they need a clean, predictable sequence: SKU-00001 through SKU-00500, ticket IDs for an event, or a run of internally consistent product numbers before you've registered anything with GS1. This tool builds that sequence in one pass, with the numeric portion zero-padded to a consistent width so everything sorts and prints cleanly.

Using the check digit option

If you turn on a check digit format, your prefix, padded number and suffix combined must be all-digits and exactly one character short of that format's full length (11 digits for UPC-A, 12 for EAN-13, 7 for EAN-8, 13 for ITF-14) — the tool then calculates and appends the correct trailing check digit using the same mod-10 algorithm as our check digit calculator. Any codes that don't fit that length are skipped and reported, so adjust your padding width if you see codes skipped.

Where the output goes next

Copy the list straight into the barcode generator textarea for a quick batch, or download it as a CSV with a value header and drop it into the bulk generator for a ZIP of individually named PNGs. If your sequence is meant to represent real retail products rather than an internal or test system, see our GS1 guide on when you actually need an officially registered number.
